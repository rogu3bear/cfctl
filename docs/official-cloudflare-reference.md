# Official Cloudflare Reference

Primary official references this repo is designed around. Use the runtime docs
bank for the compact, queryable view: `cfctl docs search "<topic>"`,
`cfctl docs changes`, `cfctl docs coverage`.

- AI docs directory: https://developers.cloudflare.com/llms.txt — full corpus at `/llms-full.txt`; append `/index.md` to any docs URL for per-page Markdown
- AI tooling style guide: https://developers.cloudflare.com/style-guide/ai-tooling/
- AI consumability guide: https://developers.cloudflare.com/style-guide/how-we-docs/ai-consumability/
