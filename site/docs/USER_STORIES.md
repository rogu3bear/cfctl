# User stories

## Epic A — evaluate trust

1. As an accountable Cloudflare operator, I want to understand cfctl's authority model before installing it so I can judge whether delegation preserves my control.
2. As a security-conscious engineer, I want to know where credentials and evidence live so I can evaluate local custody and disclosure risk.
3. As a technical evaluator, I want the product's limits and blocked paths stated plainly so I do not mistake catalog coverage for executable authority.

## Epic B — reach first success

4. As a new operator, I want a short, current install path so I can get a build whose identity I can verify.
5. As a new operator, I want to run `doctor` before authentication so I can detect environment and backend problems early.
6. As a scoped-token user, I want an explicit account-bound import path so ambiguity cannot silently select another account.
7. As an evaluator, I want one bounded live-read example so I can prove the credential and catalog path without authorizing a mutation.

## Epic C — understand change governance

8. As an agent user, I want to see the sequence from intent to resolution, plan, approval, apply, and verification so I know where authority crosses a boundary.
9. As an approver, I want costs, permissions, targets, rollback, and warnings attached to an operation ID so consent cannot drift to another change.
10. As an incident responder, I want deployment and live readback separated so I can identify the lowest unproven layer.

## Epic D — use the site inclusively

11. As a keyboard or screen-reader user, I want semantic, useful SSR content and visible focus so the site is operable before or without hydration.
12. As a narrow-screen user, I want code samples and lifecycle content to reflow without horizontal page overflow.
13. As a motion-sensitive user, I want the story to remain understandable with reduced motion.

## Story quality notes

These stories reflect repository semantics and a proto-persona, not observed interview statements. Validate priority and wording in first-use sessions.
